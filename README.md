# WeClone - 微信多开助手

一个 macOS 微信多开工具，支持多实例、实例命名、账号绑定与目录查看。

## 功能特点

- 菜单栏常驻，不占用 Dock 空间
- 一键启动新微信实例
- 支持指定运行数量
- 显示当前运行的微信数量
- 支持关闭所有微信

## 使用方法

### 方式一：直接运行 `.app`

1. 双击 `WeClone.app` 启动
2. 点击菜单栏上的 💬 图标
3. 选择操作：
   - **启动新微信** - 添加一个新实例
   - **启动到 N 个** - 自动补充到指定数量
   - **关闭所有微信** - 关闭所有实例

### 方式二：安装到 Applications

```bash
cp -r WeClone.app /Applications/
```

然后从启动台启动即可。

## 构建与打包

```bash
# 1) 一键构建 app
./build.sh

# 2) 打包免费分发版 dmg（无需苹果开发者账号）
./package_dmg.sh
```

输出说明：
- `WeClone.app`：构建产物
- `dist/WeClone.dmg`：可分发安装包

## 系统要求

- macOS 13.0 或更高版本
- 已安装微信应用

## 免费分发（无开发者账号）

可以直接分发 `dist/WeClone.dmg`，但首次运行可能会被 macOS 安全策略拦截。

用户侧操作：
1. 双击 `.dmg`，拖拽 `WeClone.app` 到 `Applications`
2. 首次运行若提示“无法验证开发者”：
3. 打开 **系统设置 > 隐私与安全性**
4. 在底部找到被阻止应用，点击 **仍要打开**

## 首次运行（本机）

首次运行时，系统可能会提示"无法验证开发者"，请按以下步骤操作：

1. 打开 **系统设置** > **隐私与安全性**
2. 找到"已阻止使用 WeClone"的提示
3. 点击 **仍要打开**

## 常见问题

**Q: 为什么菜单栏图标没有显示数量？**
A: 没有运行微信时显示 `W+`，运行后显示 `W+ N`。

**Q: 点击按钮后微信没有启动？**
A: 请确保微信已安装在 `/Applications/` 目录下。

**Q: 支持多少个微信实例？**
A: 理论上不限，但建议控制在 2-5 个以保证性能和稳定性。
