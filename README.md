# WeClone - 微信多开助手

macOS 微信多开工具：点一下「再开一个」，新的微信就坐到旁边。每个账号独立数据、互不串号，登录对不上还会提醒你。

## 功能特点

- **一键多开**：点一下「再开一个」，副本秒级创建；支持一键补齐到指定数量
- **账号不串**：记住每个窗口登录的账号，登录对不上立刻发系统通知提醒
- **原生设置面板**：macOS 原生左右两栏（总览 / 账号 / 维护 / 关于），每个微信窗口一张状态卡片
- **轻盈不占地**：副本用写时复制创建，几乎秒开、占用更小；旧副本一键瘦身
- **自动更新**：自动检查新版本，弹窗确认后自动完成安装，账号和设置原样保留
- **菜单栏常驻**：运行数量随时可见，不占用 Dock
- **数据隔离**：每个微信窗口独立的数据容器，聊天记录互不打扰

## 下载

- 最新版：<https://github.com/asiyoua/weclone/releases/latest>（附件 `WeClone-<版本>.dmg`）

安装：打开 DMG，把 WeClone 拖进「应用程序」。首次运行如提示安全确认，到「系统设置 → 隐私与安全性」点「仍要打开」。

## 使用方法

1. 双击打开 WeClone，主窗口即是设置面板（总览 / 账号 / 维护 / 关于）
2. 在「总览」点 **再开一个**，或设定数量一键补齐
3. 新窗口用另一台手机的微信扫码登录
4. 到「账号」页点 **记住当前账号**，窗口和账号就绑定在一起了

菜单栏图标 `W+ N` 表示正在运行的微信数量，点开可再开、全部关闭或打开管理面板。

发布 Release 时，除带版本号的 DMG 外，请再上传一份固定名 `WeClone.dmg`——官网与介绍页的「最新版直链」依赖这个文件名。

## 常见问题

**Q: 会很占磁盘空间吗？**
A: 副本采用写时复制，占用比整包复制小得多。每个微信的数据大小在「账号」页卡片上可见；聊天数据建议用微信自带的「存储空间」清理。

**Q: 怎么更新？**
A: 应用启动后自动检查更新（默认每 24 小时一次），发现新版本弹窗确认后自动安装，账号和设置原样保留。也可以在「关于」页手动检查。

**Q: 点击按钮后微信没有启动？**
A: 请确保微信已安装在 `/Applications/` 目录下，且应用名称为 `WeChat.app`。

**Q: 支持多少个微信？**
A: 理论上不限，建议控制在 2-5 个以保证性能和稳定性。
